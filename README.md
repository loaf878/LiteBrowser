# LiteBrowser 

A lightweight Windows desktop web browser built with .NET 10 and Microsoft Edge WebView2 Using Open Code.

LiteBrowser is designed to deliver a clean, lightweight and customizable browsing experience while keeping memory usage low.

##  Key Features

- **Ultra-lightweight memory usage** – Uses approximately 20 MB of RAM with 10 tabs open (based on your reported test).
- Custom browser interface
- Multi-tab browsing
- Bookmark management
- Browsing history
- Download management
- Built-in password manager
- Password autofill
- Custom new-tab page
- Dark-themed interface
- Quick website shortcuts
- Brave browser data import
- Browser extension support

##  Technology
- .NET 10
- Windows Forms
- Microsoft Edge WebView2

##  Platform
Windows

## 🎯 Goal

LiteBrowser aims to make everyday browsing lightweight, simple and efficient without sacrificing useful browser features.
